# SAECVAR: Twilight of Antiquity

> Victoria 3 글로벌 고대 말기 토탈 컨버전 모드  
> **캠페인: 서기 600~720년 (120년)** · **문서 상태: 통합 툴체인 기획 기준선 v0.3** · **언어: 한국어**

## 프로젝트 개요

**SAECVAR**는 여러 시대의 대형 역사·대체역사 모드를 묶는 공통 브랜드이며, **Twilight of Antiquity**는 첫 시리즈 작품이다. 지구 전체를 배경으로 서기 600년의 실제 세계를 출발점으로 삼아, 고대 말기와 중세 초기로 이어지는 정치·경제·사회·종교·군사 질서의 변화를 플레이어의 선택에 따라 시뮬레이션한다.

이 프로젝트는 특정 한반도·동아시아 모드가 **아니며 전 세계를 대상으로 한다.** 로마/사산, 아라비아, 인도, 동아시아, 유럽, 아프리카, 중앙아시아, 동남아시아, 아메리카 및 오세아니아의 **지역별로 다른 역사적 조건**을 반영한다.

원작의 **현대 산업혁명용 기술·상품·생산방식·건물·직업·법률·정치·군사 콘텐츠를 고대 말기에 맞게 전면 재설계**하는 것이 목표다. 단, 게임 엔진의 하드코딩된 경제·전쟁·시간 처리 부분을 교체한다고 확정한 것은 아니며, 가능 범위를 반드시 검증한다.

## 설계 원칙 요약

- **역사적 출발점은 고증, 이후 결과는 시뮬레이션:** 실제 연표를 미래의 확정 이벤트 목록으로 만들지 않는다.
- **전 세계 동시대성:** 한 지역의 시대 구분을 세계 전체에 일률적으로 적용하지 않는다.
- **경제·인구 중심:** 단순 지도색 변경이나 이벤트 추가가 아닌, 사회구조와 제국의 성장·쇠퇴를 구현한다.
- **게임성 우선이되 고증 수준 표시:** 근거 부족 지역의 단정적 국경·인구·국가를 임의의 역사적 사실로 제시하지 않는다.
- **실현 가능성 검증:** 엔진 수준 기능은 추정으로 '구현 가능'이라 확정하지 않고 최소 예제로 확인한다.

## 분석기 우선 개발 원칙

- **결정:** Tiger 등 외부 분석기 실행 파일·라이브러리에 의존하지 않고, SAECVAR Analyzer의 파서·모드 적용 해석·의미 분석·규칙·진단 시스템을 직접 구현한다.
- **참고:** Tiger 및 다른 파서는 기능과 실패 사례를 연구하는 참고자료로만 사용한다. 제3자 코드를 복사·번안하는 경우 라이선스 의무를 별도 검토한다.
- **권장 구현:** Rust 기반 독립 CLI(언어 선택은 구현 계획으로 관리). 분석기 개발 코드 역시 시리즈 최상위 폴더 하위에 둔다.
- **검증 모델:** 정적 검증과 정적 적용 예측을 구분하며, 게임 엔진 실행 없이 실제 로딩·AI·전투·세이브를 보증하지 않는다.
- **개발 순서:** PDX 파서 → 모드 로드/오버레이 해석 → 심볼·참조 → 타입/Scope → 진단·CLI → SAECVAR 규칙·증분 검사 → 최소 엔진 실증 → 고대 경제·국가 시뮬레이션.

상세 내용은 [08 통합 로드맵](docs/08_ROADMAP_QA.md)과 [12 분석기 로드맵](docs/12_ANALYZER_ROADMAP.md)에 정리한다.

## 통합 모딩 툴체인 — 개발 원칙

기존 SAECVAR Analyzer(자체 정적 분석기)는 **SAECVAR Toolchain의 읽기·검사 코어**로 유지한다. 여기에 구조적 편집·자료 생성·빌드 코어를 추가하고 **Codex CLI/API와 Human GUI가 동일한 EditPlan·검증·변경 적용**을 사용한다. Tiger는 기능 참고자료만으로 사용한다.

분석기의 고급 기능이나 전체 GUI를 기다리지 않고, 파서·적용 해석·진단 → 안전 편집 → **소형 고대 경제 모드 수직 슬라이스** 순서로 진행한다. [상세 개발 순서](docs/17_MASTER_ROADMAP.md)를 우선 기준으로 사용한다.

## 개발 상태

현재는 **기획 문서화 단계**다. 모드가 구현되거나 Victoria 3 현행 버전에서 게임 시작·종료 연도 변경 및 120년 플레이가 검증된 상태는 아니다.

관련 결정과 다음 검증 항목은 [의사결정 기록](docs/09_DECISIONS_OPEN.md)과 [검증 체크리스트](docs/10_VALIDATION.md)를 참조한다.
