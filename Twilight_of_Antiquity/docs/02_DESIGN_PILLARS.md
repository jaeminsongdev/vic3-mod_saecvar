# 02. 핵심 게임 디자인 원칙

- 상태: 디자인 원칙 초안 (일부는 합의된 방향, 세부 메커니즘은 미확정)
- 관련: [프로젝트 헌장](01_PROJECT_CHARTER.md), [캠페인](04_CAMPAIGN_600_720.md)

## 원칙 A — 고증된 출발점, 결정되지 않은 미래

서기 600년의 국가와 사회를 가능한 한 사료·고고학에 근거하여 구현한다. 그 뒤의 실제 역사적 사건은 **가능한 시나리오**이지 **보장된 이벤트**가 아니다. 연도 하나만 충족되면 제국이 자동 붕괴·통일·종교개종하는 방식은 피한다.

- 적합: 재정 악화·군사지원 감소·지역 불만이 쌓일 때 지방 반란이 발생할 수 있다.
- 부적합: 실제 멸망 연도가 되면 제국을 무조건 삭제한다.
- 적합: 특정 세력의 성장 조건이 갖춰졌을 때 해당 국가·종교 공동체가 형성될 수 있다.
- 부적합: 600년 당시 존재하지 않은 정치체를 미래 특정 연도에 무조건 생성한다.

## 원칙 B — 팝과 생산체계가 국가의 역사를 움직인다

빅토리아 3의 강점인 인구(POP)·생산·시장·정치적 힘의 상호작용을 핵심 재미로 유지한다. 다만 시장·임금이 중심인 엔진과 현물 세·공납·부역 등이 중심인 고대 사회 사이의 차이는 **명시적인 게임적 추상화**로 해결한다.

예상 루프: 농업·수공업 생산 → 잉여·조세기반 → 행정·군사·공공사업 → 통치력·영토·교역 확대 → 사회계층·지방권력 변화 → 새로운 개혁 과제.

## 원칙 C — 하나의 연대, 다양한 지역의 속도

'서기 600년'은 전 세계에 동일한 발전 단계가 적용된다는 뜻이 아니다. 지역마다 행정 전통, 도시화, 생산기술, 대외교역, 사료 밀도가 다르다.

유럽 중심의 봉건제나 중국 중심의 관료제를 전 세계 보편 모델로 그대로 적용하지 않는다. 자료가 불충분한 지역은 임의로 상세 수치를 단정하는 대신 추정 범위를 기록한다.

## 원칙 D — 위기와 부흥은 선택과 상태의 결과

영토 팽창뿐 아니라 제국 유지·개혁·교역·행정 통합도 주요 목표가 되도록 한다. 강대국의 붕괴는 충분히 가능한 결말이지만 정답으로 고정하지 않는다. 소국도 정복 없이 생존·번영을 추구할 수 있어야 한다.

## 원칙 E — 120년에 맞는 콘텐츠 밀도

정규 캠페인은 600~720년, 120년이다. 250년짜리 역사 서사를 압축해 넣는 대신, 한 캠페인에서 의사결정과 국가 변화가 충분히 발생하도록 기술·경제·정치 변화의 속도를 다시 조정한다.

기존 게임 100년당 약 6~12시간이라는 사용자 체감에 따른 단순 추산은 120년당 약 7.2~14.4시간이며, 실제 측정치는 아니다.


## 원칙 F — 정적 분석을 먼저, 실제 엔진 검증과 구분

게임 파일의 반복 편집과 참조·문법 검증에 매번 게임을 실행하지 않도록 **자체 SAECVAR Analyzer를 우선 개발**한다. Tiger는 참고자료이며 작업 파이프라인의 필수 의존성으로 삼지 않는다.

- **정적 확인:** 문법, 선언된 참조, 파일·객체 적용 규칙의 모델, 역사 데이터 정합성.
- **정적 예측:** 이벤트의 도달 가능성, 모드 최종 적용 객체, 경제 생산·소비 의존성의 구조적 문제.
- **실행 검증:** 실제 엔진 로딩, 600년 날짜 처리, 경제·AI·전쟁·세이브, GUI. 독립 분석기로 완전히 대체할 수 없다.
- **미확인 항목:** 게임 버전별 사양이 불분명하면 '정상'이 아닌 '검증 필요'를 반환한다.

규칙과 리포트 사양은 [13 분석기 규칙·보고 형식](13_ANALYZER_RULES_REPORTS.md)에 명시한다.

## 제안: 핵심 플레이 루프

1. **5~15년:** 초기 재정·농업·행정·국경 상황 파악, 위기 대응.
2. **15~40년:** 장기 개혁·교역망 확보·군사 체계 재편.
3. **40~80년:** 국가 통합·다민족 통치·지방권력·종교·시장 변화.
4. **80~120년:** 대제국 유지 또는 새로운 지역 질서 형성, 발전 결과를 평가.

이 구간은 목표 플레이 루프일 뿐, 실제 기술·건물 밸런싱 수치는 테스트 후 결정한다.

## 플레이 성격의 다양성 (설계 제안)

| 유형 | 도전 과제 | 의미 있는 선택 |
|---|---|---|
| 광역 제국 | 지방 통제와 재정 부담 | 중앙집권·자치·군사·조세 |
| 해상 상업국 | 항로와 수출입 안정 | 항만·외교·안보·상인 이해관계 |
| 성장기 왕국 | 토지·인력·관료 제도 | 농업 강화·왕권 강화·협상 |
| 연맹·비집권 정치체 | 권력 결집과 구성체 갈등 | 통합·연합·분리와 협력 |
| 도시국가 | 상대적으로 제한된 인구·영토 | 전문 생산·통상·외교 |

실제 구현 전에는 각 유형별 대표국을 선정하고 'AI도 재현 가능한가?'를 검증한다.

## 금지해야 할 안티패턴

- 사건마다 모든 국가에 동일한 보너스/패널티 부여.
- 세계 모든 국가에 같은 기술·정부 형태를 기계적으로 부여.
- 고대에 존재하지 않은 철도·전력·현대 기업 등을 이름만 바꿔 남겨두기.
- 근거 부족을 이유로 아메리카·아프리카·오세아니아를 무주지화하기.
- 한 지역의 종교적·정치적 변화를 전 세계의 '시대 업그레이드'처럼 처리하기.
- 군사정복 외에 국가 경영의 장기적인 목표가 없는 콘텐츠.

## 우선 검증할 가설

- 인구·경제 구조 개편만으로 7세기 국가 운영의 차별적 재미를 만들 수 있는가?
- 관료·지주·성직자·상인 세력의 정치적 갈등을 실제 법률·직업·이해집단으로 나타낼 수 있는가?
- AI가 고대 경제와 전쟁을 안정적으로 운영할 수 있는가?
- 정해진 역사 강제 없이도 600~720년에 충분한 격변이 일어나는가?
