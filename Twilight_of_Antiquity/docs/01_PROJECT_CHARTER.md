# 01. 프로젝트 헌장과 범위

- 문서 상태: 기획·개발 기준선 v0.2
- 프로젝트: SAECVAR: Twilight of Antiquity
- 작성 기준일: 2026-10-16
- 범주: 확정된 목표와 작업 범위. 구체적 설계안은 별도 문서에서 제안으로 표시한다.

## 1. 브랜드·작품 구분

**SAECVAR(세크바르)**는 특정 시대나 게임에 종속되지 않는 역사 시뮬레이션 모드 시리즈의 상위 브랜드로 확정한다.

첫 번째 작품은 **SAECVAR: Twilight of Antiquity**이며, 기반 게임은 **Victoria 3**다. 다른 시대의 작품명·출시순서·개수는 아직 결정하지 않았다. 과거 대화의 BC 330, AD 210, 1066 등은 브랜드 확장 사례로서 **제작 확정 목록이 아니다**.

## 2. 캠페인 기준선 — 확정

| 기준 | 내용 |
|---|---|
| 세계 | 실제 지구를 배경으로 한 고대 말기의 역사 세계 |
| 개시 | 서기 600년 |
| 정규 범위 종료 | 서기 720년 |
| 총 플레이 범위 | 120년 |
| 지리적 범위 | 전 세계, 특정 지역 중심이 아님 |
| 모드 유형 | 역사 기반 토탈 컨버전 |
| 역사 분기 | 600년의 출발 조건은 고증, 이후 결과는 플레이어·AI·상황의 상호작용 |
| 주요 콘텐츠 방향 | 기술, 산업·경제, 인구·계층, 법률, 정치, 종교, 문화, 군사, 외교의 고대화 |

시작월·시작일, 720년 도달 시 실제 종료 동작, 자유 플레이 지원 여부는 **미확정/기술 검증 필요**다.

## 3. 이 모드가 제공할 경험

- 고대 왕국·제국을 운영하면서 농업생산, 교역망, 병력 동원과 국가재정을 상호 연결한다.
- 이미 거대한 제국도 내부 이해관계, 지역차, 행정·재정 문제 때문에 변할 수 있다.
- 소국과 성장기 정치체도 외교·제도·경제 성장으로 신흥 강국이 될 수 있다.
- 실제 역사 속 전쟁·멸망·통일·종교의 성장 등을 **고정된 스크립트 결말로 강제하지 않는다**.
- 아프리카·아메리카·오세아니아에는 각자의 정치·사회·고고학적 배경을 부여하고, 자료 공백을 빈 땅이나 무역 공백의 증거로 간주하지 않는다.

## 4. 범위 안에 있는 작업

1. 600년 시작 정치·주 소유·인구·종교·문화·경제 데이터 재설정.
2. 원작의 19세기 산업·경제 콘텐츠를 고대 말기용 상품·건물·생산방식·기술로 대체 또는 구조적으로 재설계.
3. 고대에 적합한 국가운영의 제약과 선택: 토지·조세·지방권력·군역·교역·외교.
4. 지역과 정치체별 비대칭 발전 경로, 조건 기반 일지·이벤트·디시전.
5. AI 적응, 120년 성장 곡선, 콘텐츠·경제·성능의 회귀 테스트.
6. 한국어 기획 문서를 기준으로 역사 연구 출처와 모딩 기술 검증 기록을 축적.

## 5. 현재 범위 밖 / 확정하지 않은 것

- 지구 지형을 완전히 새로운 행성으로 바꾸는 작업(이전의 ERDAIN·The Nine Gates 구상은 현 기획에서 제외).
- 720년 이후까지 정규 콘텐츠를 제작하는 약속.
- 임의의 시대를 한 모드에 북마크로 동시 수록한다는 약속.
- 엔진의 하드코딩된 시장·전투·달력 처리 자체를 교체한다는 약속.
- 전술전투·직접 조작형 RTS 같은 별도 장르 구현.
- 임의의 배포 일정, 지원 플랫폼·DLC 요구 목록, 외부 참여 조직 체계.


## 6. 개발 도구 전략 — 확정 사항과 구현 권장안

**확정된 방향:** Tiger를 실행·링크하지 않고, SAECVAR 자체 정적 분석기를 개발한다. 이 분석기는 PDX Script 구문과 정의·참조·로드 규칙을 독립적으로 해석하여 게임 미실행 상태에서 가능한 오류를 포착하는 것이 목적이다. 분석기의 정적 예측을 실제 게임 엔진 로딩·시뮬레이션 성공으로 간주하지 않는다.

**현재 권장안:** Rust로 `Twilight_of_Antiquity/tools/saecvar-analyzer/`에 개발하여 향후 시리즈 재사용 가능성을 검토한다. 실제 코드, CLI 명령, CI 실행은 아직 구현하지 않았다.

**최우선 순서:** 파서 → 모드 적용 해석 → 의미·참조 분석 → 검증·진단 CLI → 시대별 특화 검사. 필수 엔진 호환성 검증은 별도 관문으로 남겨 두며 대규모 세계 데이터 제작 이전에 실행한다.

세부 구현 경계는 [11 자체 분석기 아키텍처](11_ANALYZER_ARCHITECTURE.md), 마일스톤은 [08 통합 로드맵](08_ROADMAP_QA.md)을 따른다.

## 7. 성공의 기준

최초 공개 버전의 성공은 '국가 수'가 아니라 다음으로 평가한다.

- 600년 시작 세이브에서 720년까지 치명적 오류 없이 플레이 가능한가?
- 한 지역의 승리 공식을 전 세계 국가에 복사하지 않고도 여러 경제·정치적 발전 경로가 성립하는가?
- 산업화용 바닐라 데이터가 시대착오적 결과를 내지 않는가?
- 특정 국가의 역사를 반드시 재현시키지 않아도 120년 동안 결정할 일이 이어지는가?
- 국제교역과 지역 간 상호작용이 역사적으로 무리한 대양 간 연결을 만들어내지 않는가?

기술적 실현성 판정, 구현 순서와 문서상의 미해결 문제는 [08 로드맵](08_ROADMAP_QA.md), [09 결정 기록](09_DECISIONS_OPEN.md), [10 검증](10_VALIDATION.md)을 참조한다.
