# 10. 기술·사료 검증 체크리스트

- 상태: **검증 계획**, 아래 체크리스트 항목은 아직 완료됐다고 표시하지 않음.
- 우선순위 변경: 자체 정적 분석기 구현 → 검증 자동화 → 필요 최소한의 실제 엔진 테스트 → 토탈 컨버전 콘텐츠.
- 이 문서는 구현 가능성이나 역사적 수치를 **확정 사실로 과장하지 않기 위한 검수 기준**이다.

## 1. 자체 분석기와 엔진 검증의 경계

검증 단계는 세 층으로 분리한다.

1. **정적 규칙 검증:** PDX Script 문법·심볼·Scope 등 분석 모델에서 확정할 수 있는 항목.
2. **정적 적용 예측:** 원본+DLC+모드의 로드·객체 적용 및 이벤트·경제 연결을 분석 모델로 예측한 항목.
3. **실제 엔진 검증:** Victoria 3 실제 로드·600년 시작·720년 종료·경제·전쟁·AI·세이브·GUI 등 동적 동작.

정적 통과 결과를 런타임 성공으로 표현하지 않는다. 현재 실행 전용 headless 검증 기능은 미확인 상태로 관리한다.

## 3. 역사 데이터 검증

- [ ] 시작 국가·정치체의 존재 시점을 확인(후대 국가 선반영 금지).
- [ ] 국가별 국경과 영향권을 분리하고 불확실성을 기록.
- [ ] 주요 지역의 문화·종교·인구에 학술적 근거를 첨부.
- [ ] 상품·건물·작물·기술의 등장시기를 검토.
- [ ] 지방 행정·조세·군사동원 방식의 지역차를 검토.
- [ ] 실제 연표를 조건 기반 콘텐츠로 전환할 때 '강제 역사'가 아닌지 검토.
- [ ] 아메리카·아프리카·오세아니아의 사회를 단정적 빈 땅으로 취급하지 않음.
- [ ] 고대 역사에 현대 국가·민족·종교 분류를 그대로 투사하지 않음.

### 사료 신뢰도 분류

- **A — 높은 근거:** 동시대 기록 또는 직접적 고고학적 근거와 연구적 합의.
- **B — 연구 기반 추정:** 복수의 학술연구가 뒷받침하지만 세부 연대·범위의 이견 있음.
- **C — 게임상 재구성:** 역사적 근거가 제한적이어서 플레이를 위해 선택한 추정.
- **U — 확인 필요:** 참고자료 미확인/상충. 정식 공개 전 우선 조사.

출처 텍스트, 저자, 발행 연도, 페이지, 지역, 결론과 반론, 적용된 데이터 파일을 함께 기록한다.

## 9. 분석기 검증 결과의 증거 등급

| 상태 | 뜻 | 확인할 증거 |
|---|---|---|
| STATIC_VERIFIED | 지원하는 정적 규칙 기준으로 검사 완료 | 규칙 ID·규칙 버전·파일 범위·진단 |
| MODEL_PREDICTED | 오버레이·조건 등 정적 모델에서 예상한 결과 | 해석 경로·모드 우선순위·근거 |
| RUNTIME_REQUIRED | 엔진 실행 없이는 결론 불가 | 게임 실행·로그·세이브·UI |
| UNSUPPORTED_RULE | 분석기가 아직 검사할 수 없음 | 미지원 구문/버전/규칙 ID |

`STATIC_VERIFIED`는 **검사 대상에 한정**된 상태이며, 파일 전체가 모든 의미에서 안전하다는 보증이 아니다. 오류의 심각도(`ERROR`, `WARNING`, `INFO`)와 검증 상태는 독립 속성으로 기록한다.

세부 계약: [11 아키텍처](../architecture/ANALYZER_ARCHITECTURE.md), [12 로드맵](../planning/ANALYZER_ROADMAP.md), [13 규칙·출력](../architecture/ANALYZER_RULES_REPORTS.md).
