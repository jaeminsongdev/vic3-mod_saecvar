# assets — 편집 원본·제작 그래픽 자료

편집 가능한 이미지·문장·아이콘 소스 및 사용권 근거를 관리합니다. 이 디렉터리는 게임 엔진이 바로 읽는 `mod/gfx/`와 구분합니다.

실제 제작 단계에서 `source/`(원본 그래픽), `licenses/`(개별 라이선스/저작권 정보)를 구성하고, 필요한 게임 형식으로 변환한 결과만 `mod/` 또는 스테이징 빌드에 배치합니다.

제3자 이미지·브랜드 파일·원본 게임 에셋은 명시적인 사용·재배포 권리를 확인하지 않았다면 추가하지 않습니다. 현재 콘텐츠와 라이선스 결정은 미확정입니다.
