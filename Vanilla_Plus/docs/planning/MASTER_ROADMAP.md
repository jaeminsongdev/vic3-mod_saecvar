# SAECVAR: Vanilla Plus — 공식 Q0~Q8 로드맵

> 상태: **기획 문서만 반영, 모든 Q 단계 미착수.** 원본 [조사 로드맵](../research/07_ROADMAP_QA.md)의 의존 관계와 [F01~F18](../features/README.md)을 통합·재배치한 시리즈 공식 계획이다.

## 기능 등록·현행 버전 정책

- 세부 기능 `Fxx-Ryy` 56개는 [REQUIREMENT_REGISTER.csv](REQUIREMENT_REGISTER.csv)로 **PLANNED/PENDING/NOT_RUN** 상태를 추적한다. 이 상태는 실제 구현 완료를 뜻하지 않는다.
- Workshop·커뮤니티 수요와 기능의 범주별 연결은 [FEATURE_SOURCE_MATRIX.csv](FEATURE_SOURCE_MATRIX.csv)에 보존한다. 참고 링크가 개별 기능을 실증하는 것은 아니다.
- 모든 기능의 안전/대칭/호환성 원칙: [X01~X07](../features/CROSS_CUTTING_REQUIREMENTS.md).
- 공식 2026-10-07 개발일지: 1.14 공개 베타의 주요 변경사항을 1.15에 통합 중. 2026-10-08 발표된 State & Revolution의 변경된 예정 출시일은 **2026-11-05**. 1.15도 해당 콘텐츠와 함께 예정됐으나 실제 출시 빌드 확인이 필요하다. [패치별 검증표](../quality/VERSION_MATRIX.md).

## 기본 전략

1. 원본 게임/버전/API를 확인하고, 기능별 `SUPPORTED / LIMITED / UNSUPPORTED / PENDING`을 기록한다.
2. UI 정보 표시를 먼저 만들고, 건설·PM 같은 상태 변경 작업은 **근거 표시 → 추천 → 수동 승인 → 안전한 조건부 자동화**로 확장한다.
3. Balance Lite의 동화·악명·편입·칙령 수치들은 **실험용 가설**로 시작하여 실제 AI·장기 경제 영향을 검증한다.
4. Twilight의 M1 개발은 사용자 요청으로 중단됐으므로 공통 분석기 완성을 QoL의 선행조건으로 두지 않는다.

## 전체 흐름

```text
Q0 타깃 버전/DLC·GUI·PDX API 실현성 조사
 ↓
Q1 최소 모드 로드·정적 검사·바닐라 diff·locale/충돌 검사
 ↓
Q2 읽기 전용 정보·핵심 알림·최소 UI   F04/F05/F06
 ↓
Q3 일괄 건설·기반시설 계산·안전 예약 F01/F03
 ↓
Q4 PM 수익성 제안→수동 적용→자동화   F02
 ↓
Q5A 무역·민간투자·POP 진단           F10/F11/F15
Q5B 속국·군사·정치·연구 도우미       F12/F13/F14
 ↓
Q6 Balance Lite(옵션)               F07/F08/F09/F17
 ↓
Q7 역사뉴스·한국어·접근성·성능       F16/F18
 ↓
Q8 버전별 호환성·세이브·DLC·출시
```

Q5A/Q5B는 GUI override 충돌을 피하고 Q2~Q4 조건이 확보되면 병렬 가능하다. F18의 한국어/접근성 기본 검사와 성능 측정은 Q2부터 병행한다.

## 작업 우선순위

**P0 (첫 수직 슬라이스)**: F04 시장 읽기 → F06 최소 UI → F05 경고 → F01 건설 조작 → F03 기반시설 → F02 PM 추천·전환. F02는 F03/F04/F05의 관측과 안전 판단을 선행해야 한다.

**P1 (후속)**: F10/F11/F15 → F12/F13/F14 → F07/F08/F09의 완만한 밸런스 실험. 게임 업데이트의 군사·악명 변경 중복에 주의.

**P2 (선택)**: F17 경제·전쟁 소폭 조정 → F16 뉴스·연혁 → F18 성능·현지화 고도화. 공통 QA는 매 단계의 필수 업무이며 Q7까지 미루지 않는다.

## 릴리스 게이트 및 증거

`G0` 기술 가용성 → `G1` 정적·override·현지화 검사 → `G2` 실제 게임 로드 → `G3` 시나리오/에러 → `G4` 세이브·AI·DLC·호환성 → `G5` 성능·릴리스. 정적 검사 통과는 런타임 성공으로 인정하지 않는다.

각 `Fxx-Ryy` 요구는 실제 게임 버전, 정상/오류 테스트, 적용·중단·제거 시나리오, 관련 증거와 두 차례 연속 수정 없는 검토가 있어야 구현 완료. 이번 커밋은 **문서화 작업만 완료**.
