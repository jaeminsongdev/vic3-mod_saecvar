# Victoria 3 QoL / Vanilla+ 모드 기획 문서팩

> 작성일: 2026-10-17 · 게임: Victoria 3 · 목적: 원본 세계관과 핵심 게임성을 유지하는 편의성 및 소폭 밸런스 개선 프로젝트
> 문서 상태: 조사 기반 설계안. 현재 게임 내 동작 및 모든 링크의 호환성을 보증하지 않음.

이 문서팩은 이전 Steam Workshop 조사에서 수집한 사례를 중복 제거하고, 향후 실제 개발에 투입할 수 있도록 기능 요구사항·설계 제약·검증 항목·로드맵으로 재구성한 것이다. 시대 전환, 지도 교체, 대체역사 및 전면적인 경제체계 개편 모드와 구별한다.

## 문서 이용 순서

1. **01_PROJECT_CHARTER.md** — 목적, 범위, 원칙과 용어.
2. **02_WORKSHOP_CATALOG.md** — Steam 창작마당 사례별 제목·링크·기능·신뢰 수준.
3. **03_FUNCTIONAL_REQUIREMENTS.md** — 18개 기능군의 요구사항, 완료 기준 및 구현 쟁점.
4. **04_USER_DEMAND_GAP_ANALYSIS.md** — 커뮤니티 수요, 중복 기능과 미충족 요구 구분.
5. **05_BALANCE_POLICY.md** — 프리셋 초기 가설, 안전 장치, 플레이테스트 방법.
6. **06_ARCHITECTURE_COMPATIBILITY.md** — 패키지·디렉터리·호환성·정적 검사 전략.
7. **07_ROADMAP_QA.md** — 실행 순서, 우선순위, 인수 테스트, 출시 기준.
8. **08_RESEARCH_AUDIT.md** — 자료 근거, 제한, 재검증 목록 및 두 차례 누락 검토의 의미.
9. **09_SOURCE_INDEX.md** — 확인된 출처, 재확인해야 할 원본 및 기술 문서.
10. **10_TRACEABILITY_MATRIX.md** — 기능군별 원본 사례·사용자 요구·인수 조건 추적표.
11. **catalog.csv / requirements.csv / user_demands.csv** — 정렬·필터 가능한 표 데이터.
12. **ALL_IN_ONE.md** — 위의 주요 Markdown 문서를 한 파일로 통합한 열람본.

## 핵심 결론

- 초기 출시의 중심은 **건설 관리(F01) + 생산방식 자동화(F02) + 기반시설(F03) + 경제 정보(F04) + 알림(F05) + UI(F06)**이다.
- 동화·개종·악명·편입·칙령 수치 조정은 **별도 선택형 Balance Lite**로 분리한다.
- 원본 법률·기술·가격·외교 비용을 우회하지 않는 **Vanilla+**가 기본값이다.
- 자동화는 사용자가 명시적으로 활성화하고, 대상 주·산업·정책을 제한할 수 있어야 한다.
- 1.13 정식, 1.14 공개 베타, 향후 1.15는 변경 규칙을 분리 확인한다. 1.14 베타에서 시험한 변경이 1.15에 통합될 예정이라는 개발자 공지가 있다.
- **정적 검사는 실행 전 일부 오류 검출 수단**일 뿐, 게임 로딩 성공·GUI 정상 표시·인게임 밸런스 검증을 대신할 수 없다.

## 데이터 정확성 고지

모드명과 ID 대부분은 이 대화의 이전 조사 결과를 보존했다. 이번 문서화 과정에서 일부 대표 모드의 Steam 설명은 다시 열람했지만, **모든 모드의 현재 공개 여부·최신 패치 호환성·실제 작동을 개별 검증한 것은 아니다.** 각 행의 `검증 상태`를 반드시 확인한다. Steam 페이지의 일괄적인 경고 문구만으로 모드 삭제·사용 불가를 판정하지 않는다.
