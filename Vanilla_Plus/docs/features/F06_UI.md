## 실행 설계(엔진 지원 여부는 Q0에서 검증)

- **선행:** F04. 독립 시리즈 Twilight의 미완성 M1을 전제로 하지 않는다.
- **입력:** UI 배율·언어·표시 데이터·키보드 포커스.
- **판단:** 고밀도 검색/정렬·중복 패널 검사·부분 Undo.
- **안전 경계:** 기존 키·입력창 침범 금지, 범용 세계 상태 Undo 금지.
- **처리 순서:** 데이터 관측 → 실제 엔진 기능·법률·기술 조건 확인 → 예상 비용/영향 계산 → 근거 표시 → 사용자 승인 → 실행 직전 상태 재검증 → 정상 게임 액션 실행/불가사유 표시.
- **결과 객체(개념 설계):** `FeatureDecision { id, game_build, subject, observed_at, feasibility, evidence, estimated_effects, permitted, reasons, proposed_action }`. 실제 게임 API라고 주장하지 않는다.
- **중단/실패 복구:** 지원하지 않는 상태·데이터 부재·버전 불일치·다른 모드 충돌이면 **실행하지 않으며**, 무엇이 불가능한지 화면/로그에 남기도록 설계.

## 테스트 시나리오

- **대표 정상/오류/경계:** 한국어 긴 이름·150% 배율·Enter 키 포커스·UI 충돌.
- **정적 게이트:** 변경된 파일의 구문·참조·로컬라이제이션·동일 GUI/defines 경로 충돌·대상 게임 빌드 차이 검사.
- **실제 엔진 게이트:** 기능별 GUI 표시, 시간 진행, 원본 비용, AI·세이브/로드, 1.13/1.14(베타) 별도 검증.
