- [56개 기능 테스트 계획](ACCEPTANCE_TEST_CASES.csv): 각각 `QA-Fxx-Ryy`로 [요구사항 등록부](../planning/REQUIREMENT_REGISTER.csv)의 `Fxx-Ryy`와 1:1 연결.
- [X01~X07 공통 정책 테스트](CROSS_CUTTING_TEST_CASES.csv): 모든 기능에서 점검하며 `NOT_APPLICABLE` 근거가 없으면 생략하지 않는다.
- [패치별 검증표](VERSION_MATRIX.md): 1.14 베타의 시험 결과를 1.15 정식 지원으로 잘못 처리하지 않는다.

### 실행 및 출시 순서

Q0에서 지원하는 엔진 명령/GUI API부터 식별하고, `IMPLEMENTATION`과 `RUNTIME_VERIFIED` 상태를 독립 관리한다. 일부 기능은 게임 스크립트로 제공할 수 없는 수치나 UI를 요구할 수 있으므로 `LIMITED/UNSUPPORTED`이면 범위를 축소하고 제한사항을 문서화한다. 각 테스트 결과에는 게임빌드·DLC·모드 커밋·테스트 ID·재현 절차·증거 링크를 기록한다.

### 전 기능 체크리스트

- [ ] Fxx-Ryy 별 구현 가능성, 원본 파일·버전·DLC, 예상 비용·실제 결과 분리
- [ ] 정상/오류 fixture, 게임에서 모드 로딩, UI·AI·세이브 증거
- [ ] 비활성화·모드 제거 경로와 충돌 패치/불가 기능 설명
- [ ] Balance Lite는 수치가 **제안값**임을 유지하고 장기 A/B 필요
- [ ] 두 번 연속 파일/링크/테스트 결과 재검토 후 수정 없으면 해당 단계 완료 처리
