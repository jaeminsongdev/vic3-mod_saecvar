# 10. 기술·사료 검증 체크리스트

- 상태: **검증 계획**, 아래 체크리스트 항목은 아직 완료됐다고 표시하지 않음.
- 이 문서는 구현 가능성이나 역사적 수치를 **확정 사실로 과장하지 않기 위한 검수 기준**이다.

## 1. 기술 검증: 최소 실행 환경부터

- [ ] 실제 Victoria 3 버전, 운영체제, 모드 로딩 방식 기록.
- [ ] 빈 모드 정상 로드 및 에러 로그 확보.
- [ ] 시작 연도 600년 변경 가능성 및 UI·저장/불러오기 정상 동작 확인.
- [ ] 720년까지 진행 및 종료/계속 플레이 처리 검증.
- [ ] 게임 속도·시뮬레이션 성능 장기 측정.
- [ ] 고대 상품·건물·생산방식의 생성·교체 및 가격·수요가 작동하는지 확인.
- [ ] 신규 또는 대체 기술트리와 해금 조건·AI 연구가 동작하는지 확인.
- [ ] 법률·이해집단·직업·POP·건물 소유권의 수정 가능 범위 확인.
- [ ] 도시·주·프로빈스·정치체 국경 배치 변경과 지도 로케이터 정상 여부 확인.
- [ ] 고대 병종·군수·전선·해상 이동 관련 데이터의 수정 가능 범위 확인.
- [ ] 조건 기반 국가 형성·정부 변동·종교 변화·외교/속국 상태 변경 실증.
- [ ] 세이브 호환성, 현행 패치와 DLC 의존성 확인.

## 2. 역사 데이터 검증

- [ ] 시작 국가·정치체의 존재 시점을 확인(후대 국가 선반영 금지).
- [ ] 국가별 국경과 영향권을 분리하고 불확실성을 기록.
- [ ] 주요 지역의 문화·종교·인구에 학술적 근거를 첨부.
- [ ] 상품·건물·작물·기술의 등장시기를 검토.
- [ ] 지방 행정·조세·군사동원 방식의 지역차를 검토.
- [ ] 실제 연표를 조건 기반 콘텐츠로 전환할 때 '강제 역사'가 아닌지 검토.
- [ ] 아메리카·아프리카·오세아니아의 사회를 단정적 빈 땅으로 취급하지 않음.
- [ ] 고대 역사에 현대 국가·민족·종교 분류를 그대로 투사하지 않음.

### 사료 신뢰도 분류

- **A — 높은 근거:** 동시대 기록 또는 직접적 고고학적 근거와 연구적 합의.
- **B — 연구 기반 추정:** 복수의 학술연구가 뒷받침하지만 세부 연대·범위의 이견 있음.
- **C — 게임상 재구성:** 역사적 근거가 제한적이어서 플레이를 위해 선택한 추정.
- **U — 확인 필요:** 참고자료 미확인/상충. 정식 공개 전 우선 조사.

출처 텍스트, 저자, 발행 연도, 페이지, 지역, 결론과 반론, 적용된 데이터 파일을 함께 기록한다.

## 3. 테스트 가능한 데이터 테이블 권장 스키마

| 테이블 | 최소 필드 |
|---|---|
| PoliticalEntities | entity_id, local_name, English_name, year_start, region, confidence, sources |
| RegionOwnership | state_id, controller_id, authority_type, year, confidence, source |
| Demography | state_id, culture_id, religion_id, occupation_group, pop_estimate, confidence |
| Economy | region_id, good_id, production_type, capacity_assumption, evidence |
| HistoricalEvents | event_id, historical_year, region, factual_summary, dynamic_conditions, outcomes |
| MechanicsValidation | test_id, game_version, change, observed_result, log_link, status |

스키마는 참고 기준이며 파일 형식·DB·코드 생성 도구는 **미확정**이다.
