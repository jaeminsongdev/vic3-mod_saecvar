# 09. 의사결정 기록 및 미해결 질문

- 버전: v0.1
- 기준일: 2026-10-16
- 목적: **대화에서 확정한 것**과 **어시스턴트가 제안한 것**을 혼동하지 않기 위함.

## A. 확정된 결정 (D)

| ID | 결정 | 확정 정도 | 배경 |
|---|---|---|---|
| D-001 | 브랜드 이름은 **SAECVAR** | 확정 | 다른 시대 대형 모드에도 공통 사용 |
| D-002 | 첫 모드는 **SAECVAR: Twilight of Antiquity** | 확정 | 610년 중심의 고대 말기 토탈 컨버전 기획에서 출발 |
| D-003 | 기반 게임은 **Victoria 3** | 확정 | POP·경제·국가 운영 시뮬레이션 활용 |
| D-004 | 동아시아 전용이 아니라 **전 세계의 동시대 고대사**를 대상으로 함 | 확정 | 모든 지역의 정치·경제·사회 변화 반영 |
| D-005 | 기본 역사 시점은 600년, 정규 캠페인 범위는 **600~720년** | 확정 | 250년은 길어서 120년으로 축소 |
| D-006 | 기술·경제·법률·사회·군사 등 핵심 콘텐츠를 **고대 시대에 맞게 대규모 재설계** | 확정된 방향 | 원작을 단순 시대 변경이 아닌 토탈 컨버전으로 전환 |
| D-007 | 역사적 사건·강대국의 멸망을 날짜만으로 강제하지 않는 **동적 역사 진행**을 지향 | 합의된 기획 원칙 | 대체역사의 자유도와 국가경영 중심 |
| D-008 | 실제 지구의 고대사를 기준으로 하고 완전한 가상 세계지도 구상은 채택하지 않음 | 방향 확정 | 세계사 중심 시나리오를 선택 |

D-002의 'Twilight of Antiquity'는 대화상 첫 프로젝트의 이름으로 계속 사용된 기준선이다. 필요하면 브랜드와 작품명을 별도 결정 기록으로 바꿀 수 있다.

## B. 결정의 결과로 산출된 수치 (A: 추정)

## C. 검토한 뒤 채택하지 않은 구상 (S: superseded)

| 이전 구상 | 현재 처리 |
|---|---|
| ERDAIN / The Nine Gates 등 완전 창작 행성과 세계지도 | 현 작품에 적용하지 않음 |
| 1836년 중심 나폴레옹·혁명 대체역사 | 이번 첫 모드의 범위 아님 |
| 삼국·고조선만 다루는 지역 고대사 | 글로벌 고대 말기 세계사로 확장 |
| 610년 시작 및 600~850년 250년 캠페인 | **600~720년**으로 재결정 |
| OMNEVAR 등 이전 브랜드 후보 | **SAECVAR**로 최종 결정 |
| 다른 연도의 모드를 한 시리즈에서 반드시 제작 | 브랜드 확장 가능성일 뿐 제작 확정 아님 |

## D. 권장안 또는 검증 전 제안 (P: proposed)

- P-001: 지구의 원작 지형 데이터를 재사용하되 600년 정치·인구·경제·주 데이터를 교체.
- P-002: 600~630 / 630~660 / 660~690 / 690~720년을 콘텐츠 설계 참고 구간으로 사용.
- P-003: 농업잉여·조세·상업·지방 통치의 고대 경제 시뮬레이션 루프.
- P-004: 국가별 비대칭 기술·법률·교역·정치 경로.
- P-005: 지역별 정치체/사료 신뢰도 기반 데이터 구축.
- P-006: 기술 실증→수직 슬라이스→글로벌 확대 순서로 개발.
- P-007: 720년 이후 자유 플레이와 다른 시대 북마크는 후속 검토.
- P-008: 구현 세부(새 POP 직업, 속국 모델, 고대식 군대, 일지 UI)는 게임 버전별 검증 뒤 확정.

## F. 결정 기록 운영 규칙

새 결정은 D 번호를 추가한다. 기존 결정을 변경할 때는 해당 행을 조용히 삭제하지 말고 '대체됨'과 근거 및 대체 ID를 남긴다. 구현 가능성 검증 결과는 [10 기술 검증](10_VALIDATION.md)에 링크한다.
